# MES Cart Tracking System

A proof-of-concept Manufacturing Execution System (MES) style application for tracking carts, operational activity, and station status.

## Project Overview

This project demonstrates how operational data can flow through a backend application, database, and web dashboard.

### Architecture

KEYENCE SR-X300
        ↓
     TAG_ID
        ↓
   FastAPI Backend
        ↓
    SQLite Database
        ↓
   MES Dashboard

## Features

- Cart tracking
- TAG_ID management
- Cart scan history
- Station monitoring
- REST API
- SQLite database
- Real-time dashboard updates
- FastAPI backend
- HTML/CSS/JavaScript frontend

## Technology Stack

- SQL

## Current Status

This is currently a proof-of-concept/demo environment.

The next phase will involve connecting the physical KEYENCE SR-X300 scanner through Ethernet and transitioning toward a production SQL Server/MES environment.
